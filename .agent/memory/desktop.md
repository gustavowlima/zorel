## avoid

- Playwright newPage/newContext in Electron: Target.createTarget not supported; tabs are created by main
- detecting a human via before-mouse-event/input-event: input via CDP also fires them (tested); use the transparent layer

- letting electron-builder pick a certificate from the keychain: it took an Apple Development one and produced an app macOS kills (SIGKILL without message)
- server inside Electron's main: dies with the window and would require Node instead of Bun
- agents' browser: there is NO native browser nor remote-debugging-port (removed 2026-11-04: unauthenticated CDP gave control of the window to any local process); the server uses its own Chromium over pipe and the panel streams frames; no browser ships (2026-11-11, −202 MB): the server tries Chrome, then Edge, else downloads Playwright's chromium-headless-shell once into <data>/browser/engine (browser.ts installChromium: the compiled server runs playwright's cli.js as Bun via BUN_BE_BUN=1). The browser closes after 15 min unused and unwatched (logins saved) and reopens on use
- __dirname is pinned by bun build to the src path: use app.getAppPath() (preload, icon, root in dev)
- desktop title bar (TitleBar in sidebar.tsx, h-12, pl-21): macOS buttons (trafficLightPosition 18,18), back/forward (brand lives in the rail, no + button); page header (Screen and chat) uses ui PageHeader: on desktop it portals into #titlebar-slot, title 12px from the card edge (left group w-77 = rail + sidebar; when collapsed, follows the arrows). Flag read inside App (main.tsx sets data-shell after the imports)
- 2026-11-04: open at login (ipc login:get/set only from the app window; opened by login does not open a window) and electron-updater 6.8.11 (checkForUpdatesAndNotify on open and every 6 h; publish github with fixed owner/repo of owner/repo in electron-builder.yml; mac target dmg+zip); release script (electron-builder --publish always) and release job in CI on tag v*. Test the desktop with another instance: --user-data-dir=<folder> (single instance per userData)
- version: `version` in apps/desktop/package.json (0.6.0 on 2026-11-10); tag v<version> triggers the release job
- without Developer ID: afterSign signs ad hoc and the update on macOS runs the release's install.sh (runInstaller); BUT macOS 27 blocks ad hoc apps (syspolicyd "Evaluating blocked code", and the .app vanished from the folder) even without quarantine — only Developer ID runs bundled; Windows/Linux update by themselves without signing

- dev with hot reload (2026-11-11, user: desktop is the focus): electron-vite 6.0.0 (apps/desktop/electron.vite.config.ts) builds main and preload as CJS into dist/{main,preload}.cjs and the window's interface from apps/web (root ../web, its vite.config spread in; outDir ../web/dist, which packaging copies). `bun run desktop:dev` = `ZOREL_DEV_PORT=4327 electron-vite dev --watch`: the window loads Vite (ELECTRON_RENDERER_URL, 127.0.0.1:5173) with HMR, preload changes reload, main changes restart Electron. The secret header also goes to the Vite host (its proxy passes it on); web vite.config proxies to ZOREL_DEV_PORT ?? 4317, so `bun run dev` (4317) and desktop:dev (4327) run side by side. Under electron-vite dev the quit question is off (a restart is a quit); SIGTERM/SIGINT quit without asking. The interface's Vite plugins are also desktop devDependencies (the config is bundled from apps/desktop and resolves from there). Dev still uses ~/.zorel unless ZOREL_HOME is set; test with --user-data-dir (single instance lock)
- app icons (2026-11-11): ipc apps:icons (preload zorelDesktop.appIcons) draws icons from app paths: icon files (png/svg under icons|pixmaps dirs, ≤512 KB) as data URLs, else nativeImage.createThumbnailFromPath 64px (real .app icon on macOS/Windows), else app.getFileIcon; only .app/.lnk/.exe or icon-folder images are accepted so a page can't thumbnail arbitrary files; cached per run
