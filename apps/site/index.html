Questions

What do I need to run it?

A sign-in to Claude Code, Codex or OpenCode, the subscriptions you already pay for. Through OpenCode, any model with an API key works too.

Where does my data live?

On your computer. Chats, memory and files stay in Zorel's data folder; API keys and sign-ins go to the system keychain.

Can an agent run anything it wants?

No. Each agent has an access level: Workspace, Ask first or Full access. Below full access it runs in the operating system's sandbox, and risky steps wait for your approval.

How does it update?

The app checks for new versions and shows a notice when one is ready. Running the install command again also updates it.
